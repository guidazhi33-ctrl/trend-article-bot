# 📈 フォロワー獲得 完全プレイブック

> **本システムの最重要 KPI は「フォロワー獲得」です。**
> このドキュメントは、 trend-article-bot が "自動で" やってくれる施策と、
> "あなたが手動で必ずやるべき" 施策の両方を、優先順に整理したものです。

---

## 0. 期待値の目安

完全自動化された投稿だけでフォロワーが爆増することはまずありません。
本システムは「**毎日継続的に質の高い投稿を出し続ける**」という、
人間が最も挫折しやすい部分を肩代わりします。
そこに **あなたが 1 日 15-30 分だけ手動で介入** することで、
3〜6 ヶ月で note・X 共に 1,000 フォロワー到達が現実的な目標になります。

| ステージ | note フォロワー | X フォロワー | 期間目安 |
|---|---|---|---|
| 立ち上げ | 0 → 100 | 0 → 200 | 〜30 日 |
| 認知期 | 100 → 500 | 200 → 1,000 | 30 → 90 日 |
| 拡大期 | 500 → 2,000 | 1,000 → 5,000 | 90 → 180 日 |

## 1. システムが自動でやってくれること(あなたの手間ゼロ)

### ✅ 記事(note)側
- **タイトル磁力の最大化**: `【】+数字+ベネフィット` を必ず満たすプロンプト設計
- **保存価値の高い構造**: 8 セクション+Q&A+次回予告で「保存される記事」を量産
- **フォロー誘導 CTA**: 記事冒頭と末尾に「フォローしておくと通知が届きます」を自動挿入
- **連載示唆**: 末尾に「次回は ◯◯ について書きます」を自動追加 → プロフィール訪問動機を作る
- **コメント誘発質問**: 末尾の「あなたの意見も聞かせてください」が読者の自己表現欲を刺激
- **サムネ最適化**: 巨大数字+対比強配色+カテゴリバッジで一覧画面で目立つ

### ✅ X 側
- **時間帯最適化**: JST 7-9 / 12-13 / 18-22 時に集中投稿(`engagement_optimizer.py`)
- **フックパターン回転**: 「🚨知らないと損」「📊3 つの数字」など 8 パターンをランダム
- **動的ハッシュタグ**: 朝は `#今日の戦略`、夜は `#明日の戦略` のように時間帯で変化
- **CTA 入り**: 「👉 フォローで毎日キャッチ」を全ツイートに自動挿入
- **ニュース翻訳の反応誘発**: 「💬 あなたはどう動きますか?」で必ず疑問を投げる

## 2. **あなたが必ず手動でやるべきこと**(1日15-30分)

これをやらないと、いくら自動投稿しても伸びません。

### 🎯 最優先(毎日)
- [ ] **プロフィール最適化**(初回 1 回・最重要)
  - X: ヘッダー画像 + プロフィール文に「何の専門家か」「フォローで何が得られるか」を 30 字以内で
  - 例: 「金融トレンドを毎日 10 本深掘り | 株/FX/暗号資産 | 元証券マン目線 | DM 開放」
  - 固定ツイート: 「自己紹介+最も反響の大きかった記事+フォロー CTA」
  - note: プロフィール画像、ヘッダー、自己紹介、「マガジン」機能で連載化(下記参照)
- [ ] **記事公開後の note 内施策**(各記事 5 分)
  - 関連する自分の過去記事へ内部リンクを貼る(滞在時間+回遊性向上)
  - 「マガジン」に追加して連載として整理(`金融トレンド徹底解剖 Vol.◯` 等)
  - 公開直後に自分で「スキ」(初動エンゲージで露出率上昇)
- [ ] **X 投稿の直後リプライ**(各ツイート 1 分)
  - 自分のツイートに自分でリプライして「補足の具体例」を追加 → スレッド扱いで露出↑
  - ツイートのリプ欄で読者の質問に **5 分以内に返答** (アルゴリズム加点)

### 🎯 高優先(週 2-3 回)
- [ ] **大型アカウントへの "良質リプライ"**(1 回 20 分)
  - 金融系インフルエンサー(@RodFinance、@kyoshin_finance 等)の投稿に
  - 1 行のお世辞ではなく「**自分の視点を加えた中身のあるコメント**」をリプ
  - うまく刺さると数千〜数万 imp が乗り、プロフィール流入が発生
- [ ] **過去記事の "リサイクル投稿"**(週 1 回)
  - 反響の良かった記事を 1 週間後・1 ヶ月後に別フック・別時間帯で再投稿
  - X Free tier は月 500 投稿。記事+ニュースで 480/月 使うので残り 20 はリサイクルに割く
- [ ] **「人気記事マガジン」更新**(note)
  - 反響の大きかった記事だけを集めた有料マガジン(¥500 程度)を作成
  - 「収益化してる人」と認識されると逆にフォローが増える(信頼の代理指標)

### 🎯 中優先(月 1-2 回)
- [ ] **コラボ・対談企画**(月 1 回)
  - 同規模の金融系クリエイターに DM で対談記事を持ちかける
  - 互いのフォロワーに紹介し合うことで非線形に伸びる
- [ ] **数値レポート公開**(月 1 回)
  - 「先月の全ポジション結果」「先月読まれた記事 Top 5」など内部データを公開
  - 透明性は note で最強のフォロー動機の一つ
- [ ] **Voicy / Stand.fm への横展開**(任意)
  - 同じ記事の要約を音声化 → 別プラットフォームから note への流入

## 3. やってはいけないこと(逆効果リスト)

| NG 行動 | なぜ NG か |
|---|---|
| 相互フォロー垢の量産フォロー | アルゴリズムが "質の低いフォロワー" と判定 → 露出↓ |
| 「フォローしてください」連投 | スパム判定。CTA は 1 ツイート 1 回まで |
| 同じツイートのコピー再投稿 | X の重複検知でシャドウバン |
| 政治・宗教・他者批判 | 金融クラスタは保守的。離脱率が跳ね上がる |
| 1 日に 20 ツイート超 | Free tier 上限突破 + 質の低下シグナル |
| AI 丸出しの文体 | 「いかがでしたでしょうか」「〜について解説していきます」を多用しない |

## 4. ダッシュボードと KPI

毎週日曜に下記を 5 分で記録するスプレッドシートを作るのを推奨。

| 指標 | 目標(立ち上げ期) | 取得元 |
|---|---|---|
| note フォロワー増加数 / 週 | +30 以上 | note ダッシュボード |
| X フォロワー増加数 / 週 | +50 以上 | X Analytics |
| 記事平均スキ数 | 10 以上 | note |
| 記事平均ビュー数 | 500 以上 | note |
| ツイート平均インプ | 1,000 以上 | X Analytics |
| プロフィールクリック率 | 2% 以上 | X Analytics |

クリック率が 2% を切る週が 2 週続いたら、フック文や時間帯の見直しが必要。

## 5. 1 ヶ月後にやる "システムチューニング"

データが溜まったら、`engagement_optimizer.py` の以下を実データで調整:

- `_HOOK_PATTERNS` ... 反応の良かったフックパターンの比率を上げる
- `_X_CTA_PATTERNS` ... CTA 文言を A/B テストで絞り込む
- cron 時刻 ... 自分のツイートで最もインプが伸びた時間帯に集中
- `pick_hashtags(n=3)` の n ... 多すぎるとスパム判定、少なすぎると拡散しない。 3 → 4 に増減を試す

## 6. 心構え

- **小さくバズるより、 30 日連続投稿** のほうがフォロワーが増える
- **記事 1 本 1 万字** より **連載 10 本** のほうが「フォローする理由」が生まれる
- **note と X は相互参照** が肝心。X で気になった→ note で読み込んだ→フォロー、の動線を作る
- フォロワー獲得は **複利**。最初の 100 人までが最も大変、ここで折れないことが全て
